KGB ACADEMY - site à héberger sur GitHub Pages

Fichiers :
- index.html : la page du site (ne change pas ce nom)
- favicon.png : petite icône de l'onglet
- logo-kgb-academy.png / .svg : ton logo

Étapes (depuis le téléphone) :
1. Extrais le zip avec l'application Fichiers ou ZArchiver.
2. Crée un compte sur github.com et confirme ton e-mail.
3. Crée un dépôt PUBLIC (New repository), par exemple "kgb-academy", avec "Add a README file" coché.
4. Dans le dépôt : Add file > Upload files, choisis les 4 fichiers (index.html, favicon.png, logo-kgb-academy.png, logo-kgb-academy.svg), puis Commit changes.
5. Settings > Pages > Source : Deploy from a branch > Branch : main, dossier /(root) > Save.
6. Attends 1 à 2 minutes. Ton site sera sur : https://TON-PSEUDO.github.io/kgb-academy/
