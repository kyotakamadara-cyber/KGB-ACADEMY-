KGB ACADEMY - site installable (PWA) pour GitHub Pages

Fichiers (9) :
- index.html : la page du site (ne change pas ce nom)
- manifest.webmanifest : informations de l'application (nom, couleurs, icônes)
- sw.js : permet l'installation et le fonctionnement hors connexion
- icon-192.png, icon-512.png, icon-maskable-512.png : icônes de l'application
- favicon.png : icône de l'onglet
- logo-kgb-academy.png / .svg : ton logo

Mise à jour du dépôt existant (depuis le téléphone) :
1. Extrais le zip avec l'application Fichiers ou ZArchiver.
2. Ouvre ton dépôt sur github.com (Chrome, "Version pour ordinateur" si besoin).
3. Add file > Upload files : choisis TOUS les fichiers du dossier extrait.
   Ceux qui existent déjà (index.html, favicon.png, logos) sont remplacés.
4. Commit changes. Attends 1 à 2 minutes.
5. Ouvre le site dans Chrome, ferme et rouvre la page : le menu ⋮ propose "Installer l'application".
